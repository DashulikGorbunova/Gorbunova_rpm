# Лабораторная №2. Когда индексов недостаточно

[Полный отчёт с измерениями и ответами](docs/report.md). [Исходные JSON-планы](docs/plans/).

Запуск из корня репозитория, Python 3.12+, Docker:

```bash
export PG_CONTAINER=rpm-lab02-replay
bash lab-01/scripts/start-db.sh
python lab-02/scripts/experiments.py
python lab-02/scripts/report.py
python lab-02/scripts/validate.py
```

Нужен новый выделенный контейнер: скрипт отказывается работать, если схема `lab02` уже существует. Он создаёт только `lab02`, не изменяет `service.orders` и данные первой работы. Потребуется несколько ГБ диска. PostgreSQL 17 закреплён digest в скрипте запуска первой работы; Compose для запуска одного контейнера не требуется.

Измерения: события 10k/100k/1m/5m, заказы 100k/1m/5m. Каждый запрос выполняется три раза; в отчёте медиана `Execution Time`, все три плана сохранены. Операции записи выполняются с `ROLLBACK`, затем `VACUUM ANALYZE`. Времена зависят от оборудования и кеша, не являются нормативом. Сервис и определения его таблицы/индексов импортируются из `lab-01/`.
