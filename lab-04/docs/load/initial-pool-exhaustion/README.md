# Первая попытка до исправления времени жизни соединений

Исходная попытка baseline при 500 пользователях: 678 завершённых ответов, 66 HTTP 500, исчерпание QueuePool 5+10. Это отдельный диагностический прогон, не входит в итоговый график.

Основная пара выполнена после одинакового для обоих режимов исправления: соединения чтения освобождаются до ожидания кеша и сериализации HTTP-ответа. Серверный лог здесь сокращён после первых повторяющихся traceback; CSV сохранены полностью.
